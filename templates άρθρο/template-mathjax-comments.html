    Inline: η δευτεροβάθμια είναι $\dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ και το ολοκλήρωμα Gauss $\displaystyle\int_{-\infty}^{+\infty} e^{-x^2}\,dx = \sqrt{\pi}$.

    Με τα custom macros: έστω $\bv{x} \in \RR^n$, τότε $\norm{\bv{x}}^2 = \bv{x}^\top \bv{x}$. Η βαθμίδα της απώλειας είναι $\pd{\mathcal{L}}{\bv{w}}$. Αναμενόμενη τιμή: $\EE[X] = \int x\,p(x)\,dx$.

    Αριθμημένη εξίσωση (το \label επιτρέπει αναφορά αλλού):

    \begin{equation} \label{eq:bayes} P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)} \end{equation}

    Αναφορά με \eqref: όπως αποδεικνύεται στην \eqref{eq:bayes}, η εκ των υστέρων κατανομή είναι ανάλογη της πιθανοφάνειας επί την εκ των προτέρων.

    Οι τέσσερις εξισώσεις Maxwell (align με αριθμό ανά γραμμή):

    \begin{align} \nabla \cdot \bv{E} &= \frac{\rho}{\epsilon_0} \label{eq:gauss-e} \\[4pt] \nabla \cdot \bv{B} &= 0 \label{eq:gauss-b} \\[4pt] \nabla \times \bv{E} &= -\pd{\bv{B}}{t} \label{eq:faraday} \\[4pt] \nabla \times \bv{B} &= \mu_0\bv{J} + \mu_0\epsilon_0\,\pd{\bv{E}}{t} \label{eq:ampere} \end{align}

    Η εξίσωση \eqref{eq:faraday} (Faraday) και η \eqref{eq:ampere} (Ampère–Maxwell) αποτελούν τον πυρήνα του ηλεκτρομαγνητισμού. Το \eqref{eq:gauss-b} εκφράζει την απουσία μαγνητικών μονοπόλων.

    Περιβάλλον cases:

    $$f(x) = \begin{cases} \phantom{-}x^2 & \text{αν } x \geq 0 \\[4pt] -x^2 & \text{αν } x < 0 \end{cases}$$

    Πίνακας (bmatrix) και ορίζουσα:

    $$\mathbf{A} = \begin{bmatrix} a & b \\ c & d \end{bmatrix}, \qquad \det(\mathbf{A}) = ad - bc, \qquad \mathbf{A}^{-1} = \frac{1}{\det(\mathbf{A})} \begin{bmatrix} \phantom{-}d & -b \\ -c & \phantom{-}a \end{bmatrix}$$

    4.3 Κώδικας (Code Block)

    Python — στατιστικά χωρίς εξωτερικές βιβλιοθήκες 
    import math

def statistics(data: list[float]) -> dict:
    # Υπολογισμός μέσης τιμής και τυπικής απόκλισης
    n       = len(data)
    mean    = sum(data) / n
    var     = sum((x - mean)**2 for x in data) / n
    std_dev = math.sqrt(var)
    return {"n": n, "mean": round(mean, 4), "std": round(std_dev, 4)}

# Παράδειγμα χρήσης
data = [2.1, 3.5, 4.0, 2.8, 5.2, 3.9]
res  = statistics(data)
print(f"Μ={res['mean']}  σ={res['std']}")  # Μ=3.5833  σ=0.8975

    7. Σχόλια

    7.1 Ένα πλαίσιο σχολίων σε οποιοδήποτε σημείο

    Ρυθμίστε τα στοιχεία σας (giscus repo, disqus shortname) μία φορά στο window.COMMENTS_CONFIG, κοντά στο τέλος του αρχείου. Μετά, σε οποιοδήποτε σημείο του κειμένου θέλετε σχόλια, προσθέτετε μία μόνο γραμμή. Τα παρακάτω τρία πλαίσια είναι ζωντανό παράδειγμα των τριών τρόπων χρήσης (θα δείξουν σφάλμα/κενό μέχρι να βάλετε πραγματικά στοιχεία repo / shortname):

    Μόνο Giscus — data-provider="giscus"

    Μόνο Disqus — data-provider="disqus"

    Ο αναγνώστης επιλέγει — data-provider="choice"

    7.2 Σχόλια σε πολλά σημεία της ίδιας σελίδας

    Για ανεξάρτητα, ξεχωριστά νήματα σχολίων ανά ενότητα (π.χ. ένα κάτω από κάθε h2), απλώς επαναλάβετε το πλαίσιο με διαφορετικό data-id. Το giscus υποστηρίζει πλήρως πολλαπλά, ανεξάρτητα πλαίσια στην ίδια σελίδα. Το Disqus υποστηρίζει εγγενώς μόνο ένα ενσωματωμένο thread ανά σελίδα — αν προσθέσετε δεύτερο πλαίσιο με data-provider="disqus", θα εμφανίσει υπενθύμιση να χρησιμοποιήσετε giscus αντ' αυτού. Αν παραλείψετε το data-id, το πλαίσιο παίρνει αυτόματα id από την πλησιέστερη προηγούμενη ενότητα (h2/h3).
