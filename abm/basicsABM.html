    Βασικές εντολές της NetLogo

    Μια εισαγωγή στη NetLogo για χρήση στη Μοντελοποίηση Βασισμένη σε Πράκτορες (ABM)

    Κώστας Κούδας • Ιανουάριος 2025

    Στήσιμο σκηνικού

    Βασικό μοντέλο

    Το στήσιμο του σκηνικού γίνεται με την εντολή to setup.

    Στήσιμο αρχικού σκηνικού. 
    
	to setup
		(εδώ οι λεπτομέρειες)
	end

    Για να εκτελέσουμε αυτό που γράψαμε, πάμε στο Add Widjet, επιλέγουμε Button και γράφουμε setup στην περιοχή Commands. Έτσι, πατώντας το κουμπί setup υλοποιείται αυτό λέει το εκάστοτε πλαίσιο to setup ... end στον κώδικα.

    Στην αρχή ο καμβάς είναι κενός, οπότε πρέπει να τον γεμίσουμε. Για την ακρίβεια, πρέπει να είναι κενός ούτως, ώστε να στήσουμε αυτό που θέλουμε να οργανώσουμε ξεκινώντας από το μηδέν. Προς τούτο χρησιμοποιούμε την εντολή ca (clear all).

    Τέλος, δημιουργούμε τους πράκτρες (χελώνες) που θα εμφανιστούν αρχικά μέσω της crt. Ας δούμε κι ένα παράδειγμα δημιουργώντας $10$ χελώνες.

    Καθαρισμός περιβάλλοντος και δημιουργεία 10 χελώνων-πρακτόρων. 
    
	to setup
		ca
		crt 10
	end

    Αλλάζοντας το υπόβαθρο

    Στατικό

    Εδώ θα πειράξουμε το χρώμα του περιβάλλοντος (patches) ζητώντας (ask) ένα άλλο χρώμα γι' αυτό (set pcolor). Επί παραδείγματι, αν θέλουμε κόκκινο περιβάλλον, γράφουμε το παρακάτω.

    Φτιάχνοντας κόκκινο καμβά. 
    
	to setup
		ca
		ask patches
		[
			set pcolor red
		]
	end

    Τυχαίο

    Αν δεν μας ενδιαφέρει η μονοχρωμία και θέλουμε να χρωματίσουμε τυχαία κάποια κελιά, τότε χρησιμοποιούμε την εντολή n-of. Συγκεκριμένα, με την ask n-of 20 patches επιλέγουμε $20$ τυχαία κελιά. Έτσι, με τις παρακάτω εντολές φτιάχνουμε $20$ τυχαία κόκκινα κελιά.

    Φτιάχνοντας 20 τυχαία κόκκινα κελιά. 
    
	to setup
		ca
		ask n-of 20 patches
		[
			set pcolor red
		]
	end

    Αλλά, ας δούμε και κάτι πιο περίπλοκο. Ας επιλέξουμε αρχικά $5$ τυχαία κελιά και σε ακτίνα $10$ (in-radius 10) επιλέγουμε άλλα $15$, τα οποία και χρωματίζουμε μπλε.

    Φτιάχνοντας 15*5 τυχαία κόκκινα κελιά. 
    
	to setup
		ca
		ask n-of 5 patches
		[
			ask n-of 15 patches in-radius 10
			[
				set pcolor blue
			]
		]
	end

    Καθορίζοντας τους πράκτορες

    Οι πράκτορες καλούνται «χελώνες» στο NetLogo, εξ ου και το create turtles (εν συντομία: crt) φτιάχνει τους πράκτορες. Με το set size καθορίζουμε το μέγεθος και με το set color το χρώμα.

    Χρωματίζοντας και αλλάζοντας το μέγεθος των χελώνων 
    
	to setup
		ca
		crt 2
		[
			set size 2
			set color yellow
		]
	end

    Μεταβλητές

    Καθολικές

    Μπορούμε κάποιες παραμέτρους να τις προσδιορίσουμε αρχικά στην ενότητα globals, επιτρέποντας στον χρήστη να τις αλλάζει με μία απλή αλλαγή τιμής εκεί. Έτσι, αναφέρουμε ότι θα χρησιμοποιήσουμε τη μεταβλητή num-clusters:

    Ορισμός μεταβλητών. 
    
	globals
	[
		num-clusters
	]

    Ακολούθως δίνουμε τιμή στο num-clusters (set num-clusters) κι έκτοτε χρησιμοποιούμε αυτό. Δηλαδή, θέλοντας να έχουμε $4$ αρχικά επιλεγμένα κελιά γράφουμε:

    Φτιάχνοντας 15*n τυχαία κόκκινα κελιά. 
    
	to setup
		ca
		set num-clusters 4
		ask n-of num-clusters patches
		[
			ask n-of 15 patches in-radius 10
			[
				set pcolor blue
			]
		]
	end

    Για την κάθε χελώνα-πράκτορα ξεχωριστά

    Η globals όριζε μεταβλητές που η τιμή τους είναι μία ενιαία για όλο το πρόγραμμα και για κάθε χελώνα. Μπορεί όμως εμείς να θέλουμε μία μεταβλητή που να αφορά την κάθε χελώνα ξεχωριστά. Ας πάρουμε επί παραδείγματι τη μεταβλητή time-since-last-found. Αυτή θέλουμε (θα φανεί πιο μετά γιατί) να μπορεί να πάρει διαφορετικές τιμές από χελώνα σε χελώνα. Αυτή τη δουλειά την κάνει η turtles-own. Συγκεκριμένα, γράφουμε:

    Μεταβλητές χελώνων. 
    
	turtles-own
	[
	time-since-last-found
	]

    Κίνηση

    Απλή κίνηση

    Για να ορίσουμε την κίνηση των πρακτόρων, θα φτιάξουμε ένα περιβάλλον to go ... end και θα φτιάξουμε ένα κουμπί go (όπως φτιάξαμε και το setup), όπου θα το υλοποιεί.

    Εν προκειμένω θα φτιάξουμε $1$ χελώνα (crt 1), η οποία:

    • Θα στρίβει $90^\circ$ δεξιά (right 90)
    • Θα προχωράει μπροστά $5$ βήματα (forward 5)
    • Θα στρίβει $90^\circ$ αριστερά (left 90)
    • Θα πηγαίνει πίσω $2$ βήματα (back 2)

    Έχουμε, λοιπόν:

    Κίνηση δεξιά-αριστερά και μπρος-πίσω. 
    
	to setup
		ca
		crt 1
	end
	
	to go
		ask turtles
		[
			right  90
			forward 5
			left 90
			back 2
		]
	end

    Προφανώς, θα μπορούσαμε να είχαμε γράψει:

    Κίνηση δεξιά-αριστερά και μπρος-πίσω. 
    
	to setup
		ca
		crt 1
	end
	
	to go
		ask turtles
		[
			right  90
			forward 5
			right -90
			forward -2
		]
	end

    Αν θέλουμε να δούμε και το ίχνος που αφήνει ο πράκτορας κατά τη διαδρομή του, χρησιμοποιούμε την εντολή pen-down:

    Κίνηση δεξιά-αριστερά και μπρος-πίσω. 
    
	to setup
		ca
		crt 1
	end
	
	to go
		ask turtles
		[
			pen-down
			right  90
			forward 5
			left 90
			back 2
		]
	end

    Ας βάλουμε και λίγη τυχαιότητα στη διαδικασία, να την κάνουμε πιο ρεαλιστική. Θα χρησιμοποιήσουμε τις εντολές random και random-float. Γράφοντας π.χ.:

    • random 10 λαμβάνουμε έναν ακέραιο μεταξύ του $0$ και του $9$ (όχι το $10$),
    • random-float 10 λαμβάνουμε έναν δεκαδικό μεταξύ του $0$ και του $9.999\dots$ (όχι το $10$).

    Εν προκειμένω θα βάλουμε τον πράκτορα να κινείται μπροστά $2$ βήματα (forward 2) και κάθε που κάνει αυτά τα $2$ βήματα να κάνει μια τυχαία στροφή μεταξύ των $90^\circ$ δεξιά και των $90^\circ$ αριστερά. Για να το πετύχουμε αυτό θέλουμε έναν τυχαίο ακέραιο του διαστήματος $[-90,90]$. Έτσι, διαλέγουμε έναν τυχαίο ακέραιο του $[0,180]$ (random 181) και του αφαιρούμε $90^\circ$. Πάλι με την pen-down θα δούμε την τροχιά του πράκτορα:

    Τυχαία κίνηση δεξιά-αριστερά. 
    
	to setup
		ca
		crt 1
	end
	
	to go
		ask turtles
		[
			pen-down
			right  (random 181) - 90
			forward 2
		]
	end

    Σύνθετη κίνηση

    Για να εισαχθούμε στον τρόπο γραφής πιο περίπλοκων διαδικασιών, δεν θα ορίσουμε άμεσα στο to go ... end τι γίνεται, αλλά θα ορίσουμε ότι εντός του εκτελείται η διαδικασία search, την οποία θα ορίσουμε ακολούθως. Αυτό μάς επιτρέπει να έχουμε εντός της to go ... end διάφορες κινήσεις, χωρίς να είναι ιδιέτερα περίπλοκη η γραφή της.

    Έτσι, το προηγούμενο παράδειγμα γίνεται.

    Τυχαία κίνηση δεξιά-αριστερά. 
    
	to setup
		ca
		crt 1
	end
	
	to go
		ask turtles [search]
	end
	
	to search
		pen-down
		right  (random 181) - 90
		forward 2
	end

    Προφανώς, στην προκειμένη περίπτωση δεν χρειαζόταν κάτι τέτοιο. Το κρατάμε μόνο ως λογική, για να εισαχθούμε σε ένα περιπλοκότερο παράδειγμα.

    Εδώ θα χρησιμοποιήσουμε τον κώδικα που γράψαμε σε προηγούμενη ενότητα και που παράγει τυχαία κόκκινα κελιά και θα προγραμματίσουμε $2$ χελώνες να τα ψάχνουν. Μπορούμε να θεωρήσουμε ότι τα κόκκινα κελιά είναι η τροφή που ψάχνουν στα τυφλά οι χελώνες. Συγκεκριμένα:

    • το έδαφος χρωματίζεται κόκκινο (βλ. set pcolor red στο ask patches), τα κελιά με τροφή πράσινα (βλ. set pcolor green εντός των ask n-of), ενώ τα εδώδιμα κελιά που φαγώθικαν χρωματίζονται μαύρα (βλ. set pcolor black εντός του ifelse pcolor = green),
    • αν η χελώνα έχει βρει πρόσφατα τροφή (time-since-last-found <= 20 ), τότε εξερευνεί αρκετή περιοχή μπροστά της, δηλαδή $\pm 90^\circ$ (right (random 181) - 90),
    • αν η χελώνα δεν έχει βρει πρόσφατα τροφή (time-since-last-found > 20 ), τότε πάει σχετικά ίσια, δηλαδή $\pm 10^\circ$ (right (random 21) - 10).

    Έτσι, έχουμε:

    Ψάχνοντας τροφή. 
    
	turtles-own
	[
		time-since-last-found
	]
	
	to setup
		ca
		crt 2
		[
		set color yellow
		set time-since-last-found 21
		pen-down
		]
		ask patches
		[
			set pcolor red
		]
		
		ask n-of 5 patches
		[
			ask n-of 15 patches in-radius 10
			[
				set pcolor green
			]
		]
	end
	
	to go
		ask turtles [search]
	end
	
	to search
		ifelse pcolor = green
		[
			set time-since-last-found 0
			set pcolor black
		]
		[
			set time-since-last-found time-since-last-found + 1
		]
		
		ifelse time-since-last-found <= 20
		[
			right (random 181) - 90
		]
		[
			right (random 21) - 10
		]
			
		forward 1
		
	end
